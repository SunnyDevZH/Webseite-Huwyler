# Fritz Huwyler & Co.

Statische Website der Schuhmacherei Fritz Huwyler & Co. Seit 1958 in Familienhand, mit Standorten in Schlieren, Zürich, Basel und Bern.

## Dateien

- `index.html` — die Seite
- `img/` — Bilder und Logo
- `.htaccess` — Apache: Startseite, Zeichensatz, Bild-Cache
- `Huwyler/` — Kopie zum Hochladen

## Lokal ansehen

`index.html` im Browser öffnen.

## Hochladen

`index.html`, `.htaccess` und den Ordner `img/` in den Webroot legen (`public_html`, `www` oder `httpdocs`).
